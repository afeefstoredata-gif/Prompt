Product Requirements Document (PRD)
Project Name

ShadowStore E-Commerce Platform

Project Overview

A modern Shopify-style e-commerce website focused on a single product category. The platform will provide a clean shopping experience with responsive UI, cart management, admin controls, Google Sheets order synchronization, and automated customer order email handling.

Objectives
Build a responsive and modern e-commerce platform.
Allow customers to browse and purchase products easily.
Sync order data directly into Google Sheets.
Send formatted order details to the business email.
Provide a secure admin dashboard.
Support local development and production deployment.

Mobile users
